Where the uploaded files appear relative to the embed. Discord always shows the attachments of a message above its embeds, so files attached to the embed message appear above the embed. AFTER_EMBED: post the embed first and the files in a follow-up message right after it (more follow-ups when there are more than 10 files or they exceed the budget), so the files appear below the embed. Follow-ups go to the same channel, thread or forum post and use the same username and avatar. WITH_EMBED: attach the first files to the embed message itself; Discord shows them above the embed. Without an embed, or when no files are uploaded, a single message is posted either way. Default: AFTER_EMBED.
