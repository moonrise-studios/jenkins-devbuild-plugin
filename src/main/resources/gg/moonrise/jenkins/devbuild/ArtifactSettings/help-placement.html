Where the uploaded files appear relative to the embed. IN_EMBED: post one message that lays the embed out with Discord components: a card with a coloured accent bar, the inline fields shown as lines of text, and the first files (up to 10, within the budget) shown as download cards inside the card. Further files follow in separate messages. Text-to-speech is not available in this mode. Uploaded file names are reduced to letters, digits, ., _ and -. AFTER_EMBED: post a classic embed first and the files in a follow-up message right after it (more follow-ups when there are more than 10 files or they exceed the budget), so the files appear below the embed. Follow-ups go to the same channel, thread or forum post and use the same username and avatar. WITH_EMBED: attach the first files to the classic embed message itself. Discord always shows the attachments of a classic message above its embeds, so the files appear above the embed. Without an embed a single message with the files is posted for every option. Default: IN_EMBED.
