Posts the build to a Discord webhook as an embed and uploads the matching files (by default **/*.jar) as attachments.

Every setting is optional. Unset settings are inherited from the job property, then parent folders (nearest first), then the global configuration, then built-in defaults.

In Pipeline use discordDevBuild webhookName: 'devbuilds', artifacts: [includes: 'build/libs/*.jar']. The step works inside and outside node.
